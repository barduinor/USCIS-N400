# Dioxus 0.7 Library Docs

These docs target the Dioxus 0.7 patch line, matching the compatible Cargo
requirement `dioxus = { version = "0.7" }` (ADR 0005). Upstream 0.8 alphas
exist and are out of scope until that pin moves.

This directory is a library-doc pack, not a project coding standard. Use it to
find relevant Dioxus 0.7 documentation for components, state, routing, assets,
async work, or the web target.

## Read First

- Start with `INDEX.md` for task-specific navigation.
- Use `SOURCES.md` to confirm upstream documentation provenance.
- Prefer Dioxus 0.7 documentation over older examples from blogs, answers, or
  prior Dioxus releases.
- If a topic is not covered here, consult the upstream Dioxus 0.7 sources listed
  in `SOURCES.md`.
